Method 2: Using Betacraft proxy

    Add this line to the JVM arguments in your launcher:

    -Dhttp.proxyHost=betacraft.uk -Dhttp.proxyPort=11705

    This proxy will use proper data for versions from a1.2.0 to b1.8.1.
